# Producción de Cabaña Tupambaé

Recursos independientes:

- Repositorio: `bautistacardosob-hub/cabana-tupambae`
- Sitio Netlify: `cabana-tupambae`
- Proyecto Supabase: `cabana-tupambae`
- Cabaña: ID `1`, slug `cabana-tupambae`

Las credenciales se guardan únicamente como variables protegidas en Netlify.
Nunca deben incorporarse a Git ni reutilizarse en otra cabaña.

## Variables requeridas

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
- `SUPABASE_SECRET_KEY`
- `DATABASE_URL`
- `NEXT_PUBLIC_CABIN_ID=1`
- `NEXT_PUBLIC_SITE_URL=https://cabana-tupambae.netlify.app`

## Verificación de cada entrega

1. Ejecutar pruebas, control de tipos y compilación de producción.
2. Revisar portada, navegación, contacto y diseño adaptable.
3. Verificar inicio de sesión y acceso a `/admin`.
4. Comprobar carga de imágenes, publicación y formulario de contacto.
5. Mantener vacíos catálogo y remates hasta recibir información oficial.
